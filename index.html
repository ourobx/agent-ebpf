Deklaratif Güvenlik Politikaları

policy.yaml dosyasında tanımlanan kurallar eBPF bytecode'una derlenerek doğrudan kernel'a yüklenir.

1. Yıkıcı SQL Sorgularını Engelle
WHERE şartı içermeyen UPDATE veya DELETE komutlarını veritabanına ulaşmadan düşürür.
2. Multi-Tenant İzolasyon Zorunluluğu
Ajan sorgularında tenant_id filtresi bulunmuyorsa bağlantıyı keser.
3. Yasaklı Sistem Çağrıları (Syscall)
Ajanın Python süreci üzerinden yetkisiz alt süreç (execve, ptrace) başlatmasını engeller.
version: "v1alpha" metadata: name: "destructive-sql-shield" rules: # 1. Intercept unconstrained UPDATE/DELETE without WHERE - id: "sql-no-where-mutation" type: "db_query" protocol: "postgres" severity: "critical" action: "DROP" match: pattern: "(?i)^(UPDATE|DELETE)\\s+((?!WHERE).)*$" message: "Destructive SQL without WHERE condition blocked in kernel."

Gemini Spark & MCP SSE Gateway

Agent-eBPF, Model Context Protocol (MCP) standartlarını yerel olarak destekler.

Dahili Sunucu: mcp_server.py

Uvicorn üzerinde asenkron çalışan SSE (Server-Sent Events) protokolü ile Gemini Spark şu araçlara doğrudan erişebilir:

  • 🔍 get_security_status: Canlı kernel sayaçları ve gecikme istatistikleri.
  • 📋 get_active_policies: Aktif policy.yaml kurallarını alma.
  • ➕ add_security_rule: Sohbet üzerinden canlı kernel kuralı ekleme.
  • 🧪 simulate_query_check: Sorguyu çalıştırmadan ön test etme.
# Start MCP SSE Gateway Server
uvicorn mcp_server:app --host 0.0.0.0 --port 8000

# Startup Output
